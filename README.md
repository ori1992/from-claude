# from-claude

Skills I built for Claude Code.

## Skills

- **[paper-to-bullets](skills/paper-to-bullets/SKILL.md)**: turns a research paper into five bullets (title, question, method, result, limitation) for quick triage.

## How to use a skill

Copy the skill's folder into `.claude/skills/` inside your project (or `~/.claude/skills/` to use it everywhere), then start a new Claude Code session.
